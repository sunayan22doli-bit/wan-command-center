# WAN Command Center

A single-file HTML artifact with two views:

- **Program Dashboard** — a WAN vendor tracking dashboard: sites by phase, critical path, risk register, carrier ownership, weekly cadence, decision authority, and a 60-day lookahead.
- **Interview Prep** — a personal study reference for a Global WAN Architect interview, combining an elevator pitch, core concepts, stories, technical/behavioral Q&A, real-world scenarios, a carrier management playbook, and a 100+ question practice bank.

Open `index.html` in a browser, or serve the repo with GitHub Pages.
